=========================================
      ORYZEN 1.6.6 SETUP & USAGE GUIDE
=========================================

1. PREREQUISITES
-----------------------------------------
- Minecraft Version: 1.21.1
- Fabric Loader:     0.15.8 or higher


2. INSTALLATION STEPS
-----------------------------------------
Step 1: Open the `.jar` File
   - Open the Oryzen `.jar` file using WinRAR or any archive manager.

Step 2: Edit the Whitelist File
   - Locate and open `Whitelist.json` inside the archive.
   - Delete the default nickname.
   - Enter your intended Minecraft nickname and save the file.

Step 3: Launch the Game
   - After saving, close the archive and launch Minecraft.


3. IMPORTANT WARNING
-----------------------------------------
It is highly recommended to run Oryzen as a STANDALONE client. 

Using it alongside other clients (such as Mio Client) may lead to 
Mixin conflicts. This can cause some modules to fail or result in 
Minecraft crashing during launch or gameplay.
